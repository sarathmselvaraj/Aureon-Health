# Aureon Health Template

India-focused premium life + health insurance brokerage template.

- Client/Admin role toggle login
- Client and Admin dashboards with shared DOM/localStorage demo state
- Plans comparison, claims assistance, reminders, payments and document-vault metadata
- Light/Dark, RTL/LTR, responsive navigation
- Glassmorphism + realistic insurance/healthcare imagery

> Demo front-end only. Real deployment needs secure backend authentication, encrypted document storage, payment gateway integration, audit logging and regulatory review.
